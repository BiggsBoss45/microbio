MICROSCOPE OPERATING INSTRUCTIONS

1. Place prepared slide on microscope stage.

2. Secure slide using stage clips.

3. Begin with the lowest magnification objective.

4. Use coarse focus until specimen becomes visible.

5. Use fine focus to sharpen image.

6. Increase magnification as needed.

7. Use only the fine adjustment when using high magnification.

8. Ensure microscope lens never touches the slide.


GRAM STAIN PROCEDURE

1. Create a smear on the microscope slide.

2. Allow smear to dry completely.

3. Heat-fix by passing slide above flame three times.

4. Apply Crystal Violet for 60 seconds.

5. Rinse with water.

6. Apply Iodine for 60 seconds.

7. Rinse with water.

8. Decolorize using alcohol.

9. Apply Safranin for 60 seconds.

10. Rinse with water.

11. Dry slide.

12. Apply coverslip and examine.
